Emoji Motion + Auto Caption landing page
========================================

Open locally:
1. Double-click index.html (most features work directly), or
2. For the most reliable video/browser behavior, run a local server from this folder:
   python -m http.server 8080
   Then open http://localhost:8080

Upload:
Upload the entire folder to your hosting provider. Keep index.html, styles.css,
script.js and the assets folder together.

Included:
- 9 provided Auto Caption MP4 preview clips, with local poster images.
- Interactive responsive shape-layer demo with Red / Green / Blue controls.
- Interactive word-by-word highlight demo with Red / Green / Blue controls.
- Emoji Motion showcase with Apple-style static emoji preview and Noto 2D Animated previews.
